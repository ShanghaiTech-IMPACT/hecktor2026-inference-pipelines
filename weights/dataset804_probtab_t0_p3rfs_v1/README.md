# dataset804_probtab_t0_p3rfs_v1 Weights

Download this bundle from the [Hugging Face model repository](https://huggingface.co/SunnyXcf/HECKTOR2026), under `dataset804_probtab_t0_p3rfs_v1/model/`. It contains Dataset804 `3d_lowres` and `3d_cascade_fullres` five-fold `checkpoint_final.pth` ensembles plus the T/N/RFS tabular estimators and T0 rule. The binary files are intentionally not stored in GitHub.

`SHA256SUMS.txt` lists hashes relative to `model/`. Pair this bundle only with the matching source variant and run `python tools/verify_weight_hashes.py` after downloading.
