# dataset804_807_refine_emptytiny_t0_804p3rfs_v1 Weights

Download this bundle from the [Hugging Face model repository](https://huggingface.co/SunnyXcf/HECKTOR2026), under `dataset804_807_refine_emptytiny_t0_804p3rfs_v1/model/`. It contains Dataset804 cascade checkpoints, Dataset807 refinement checkpoints, tabular T/N/RFS estimators, and the T0 rule. The refinement variant uses the empty/tiny-mask fallback documented in its pipeline description. The binary files are intentionally not stored in GitHub.

`SHA256SUMS.txt` lists hashes relative to `model/`. Pair this bundle only with the matching source variant and run `python tools/verify_weight_hashes.py` after downloading.
